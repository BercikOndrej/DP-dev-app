# Pojdte ven React App

- A `React` application wrote in `TypeScript`
- This is development version of frontend application and part of website `www.pojdteven.cz`. This website is also my master thesis.

## App Features

- Navigating through website via `React Router` library and navigation menu
- Dark/Light theme via `Shadcn` and `Tailwind`
- Users management (login, logout, generate and reset password, authentication and authorization, and clasic `CRUD`)
- Sending emails for reset password and for info
- Attendance management for kindergarten
- Parallax photo design
- View and download files (`file-saver` library)
- Full screen photo viewing
- All photos downloading (`jszip` library)
- QR Code generating
- Action disable based on date and time (cannot enroll attendance for next day after 18:00)
- Implement `tinyMCE editor` into form for storing and editing `html` content
- Comunication with server via `Tanstack React Query`
- Using of `open API` specification for generating code (`hey Api` library)
- Own calendar management and also attendance management thanks to `Dayjs`
- Generating excel file with attendance info thanks to `ExcelJS package` for user download
- Animations thanks to `AOS package` (animation on scroll)
- Data validation and error display thnaks `zod library`
- Controlled forms by `react-hook-form`
- Dialogs for actions
- Informate user by `Toast component`
- Global state management through app thanks to `Zustand library`

## Server

- `Vite` was used as deveplopment server for run my app
- `BE` server is `Loopback 4 application`, that serves and stores data

## Used Frameworks

- `Tailwind CSS` for styling
- `Vite` for development server and React template
- `Shadcn UI` for React components (based on `Radix`)
- `Openapi ts` (with TanStack query plugin) for generating `BE endpoints` methods and model classes

## Useful Commads

- `npm run dev` for running an app by development server
- `npm run build` for building an app
- `npm run openapi-ts` for generating code from open API specification

## Projekt Structure - src Folder

- **src**
  - **assets**
    - Static files like images, logos and placeholders
  - **client**
    - Destination folder for generated files by `open api`
    - These files contains `server models definition` and methods to comunicate with server's enpoints
  - **components**
    - All React components used by application
  - **enums**
    - Here are define all enum class types
  - **hooks**
    - Definition of all `custom hooks`
  - **lib**
    - Folder generated by `shadcn CLI` that containt helper methods for righ use tailwind classes
  - **pages**
    - Files representing single pages of application
    - Devided into `admin`, `public` and `protected`
  - **services**
    - Files that ate helping with diferent logic in app
  - **stores**
    - Folder contains `Zustand store` definitions
  - **utils**
    - Folder that contains small helper methods
  - **index.css**
    - Stores cascade styles for whole application
  - **main.tsx**
    - Entry point of whole application
  - **routes.tsx**
    - Definition of `Routes` for navigation through application
- **components.json**
  - Setting file for components from `shadcn UI`
- **index.html**
  - Static html file for our website
- **openapi-ts-config**
  - Setting file for `openapi package`
- **package.json**
  - `npm` setting file
- **tailwind.config.ts**
  - Setting file for `tailwind framework`
- **tsconfig.json**
  - Setting file for `TypeScript`
- **vite.config.ts**
  - `Vite` app setting file
